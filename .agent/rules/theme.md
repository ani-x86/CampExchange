# Rule: Theme (always on)
- Background `#FFFFFF`, surface `#FAFAFA`, border `#E5E5E5`, text `#111111`, muted `#6B6B6B`, accent `#2F5BFF`.
- Border radius: `rounded-sm` (2px) default, `rounded` (4px) max. No `rounded-xl`, no gradients, no glassmorphism.
- Font: Inter (UI) + JetBrains Mono (prices, IDs).
- Animations: 120–220ms, ease-out, opacity/translate only. Wrap in `useReducedMotion`.
